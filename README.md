# Electify

An interactive and minimalistic election guide.

## Running on Google Cloud Shell

This project is configured to run effortlessly in Google Cloud Shell using Node.js.

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the application**:
   ```bash
   npm start
   ```

3. **View the app**:
   Click the **Web Preview** button in the top-right corner of Cloud Shell and select **Preview on port 8080**.
